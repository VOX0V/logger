Import

Select an import profile and one or more files (Excel or airline CSV). Each file is MERGED with the raw database: nothing is ever replaced or deleted. A flight that is already present is only completed with the fields it lacks; an unknown flight is added. Importing the same file again changes nothing. Headers not listed in the profile are ignored.

Profiles are defined in importer/import.yml. Values are imported as they are in the file; missing columns are added to the database.
