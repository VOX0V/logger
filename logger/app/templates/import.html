Import

Select one or more files (Excel, airline CSV or your Excel logbook). Each file is MERGED with the raw database: nothing is ever replaced or deleted. A flight that is already present (same date and flight number, same remarks, or same registration and airports, or same aircraft and flight time) is only completed with the fields it lacks; an unknown flight is added. Importing the same file again changes nothing. A column without a matching rule is ignored.

A profile (one file per airline in importer/) replaces the default rules for this import. Values are imported as they are in the file; missing columns are added to the database.
